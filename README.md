# AnimalUIExperiment
Android UI综合实验项目，使用Java + XML开发，实现多个UI组件实验。

## 项目简介
本项目为Android移动开发课程实验，包含列表展示、弹窗对话框、选项菜单、文字样式修改、RecyclerView、ActionMode多选删除等功能。

## 开发环境
- Android Studio
- 开发语言：Java
- 编译SDK：37
- 最低支持SDK：24

## 功能清单
1. ListView 图片+文字列表展示
2. 自定义登录AlertDialog弹窗
3. 弹出式菜单：放大/缩小字体、文字颜色切换（红/黑）
4. ActionMode 长按多选删除
5. RecyclerView列表控件实验
6. 列表点击弹出Toast通知
